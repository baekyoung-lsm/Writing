# 작품 개발 브리프 (Novel Development Brief)

## 0. 이 문서의 목적과 사용법

이 브리프는 "설정 정리"가 아니라, Claude가 이 작품의 **공동 집필가**로서 몇 개월 이상 판단을 내릴 수 있게 하는 **작업용 지식 베이스**다. 목적은 다음 두 가지다.

1. Claude가 "이 장면이 캐릭터에게 맞는가", "이 복선이 회수됐는가", "이 결말이 약한가", "이 문장이 이 작품 톤에 맞는가" 같은 질문에 **작품 내부 논리로** 답할 수 있게 한다.
2. 작가 본인도 답하면서 스스로 구조의 구멍(설정 충돌, 캐릭터 모순, 약한 결말 등)을 미리 발견한다.

**작성 원칙**

- 완벽하게 채우고 시작할 필요 없다. 초안은 거칠어도 되고, 집필하며 계속 갱신한다.
- "모르겠다/아직 정하지 않았다"도 유효한 답이다. 다만 왜 아직 정하지 않았는지, 정하지 않은 채로 둬도 되는 항목인지 표시해두면 좋다.
- 표시된 **[필수]**는 이게 없으면 Claude가 장면 단위 판단(대사, 행동, 전개)을 할 수 없는 항목이다. **[권장]**은 구조 단위 판단(플롯, 페이싱, 상업성)에 필요하다. **[선택]**은 있으면 정교해지지만 없어도 진행 가능한 항목이다.
- 항목마다 "왜 필요한가"를 적어뒀다. 이 이유가 와닿지 않는 항목은 이 작품에 안 맞는 항목일 수 있으니 비워둬도 된다.

## 1. 로그라인 & 작품 정체성

| 항목 | 필요도 | 왜 필요한가 |
|---|---|---|
| 로그라인 (주인공 + 목표 + 장애물 + 이해관계를 한두 문장으로) | 필수 | 모든 장면·대사·복선 판단의 최종 기준점. "이게 로그라인에 봉사하는가"로 장면 존재 이유를 검증한다 |
| 장르 / 서브장르 (예: 판타지 회귀물, 로맨스판타지 계약결혼물 등) | 필수 | 장르 문법(트로프, 독자 기대)을 판단하는 기준 |
| 형식과 목표 분량 (연재 웹소설/화수, 단행본/권수, 시나리오/분량 등) | 필수 | 페이싱과 구조 설계가 형식마다 완전히 다르다 |
| 연재 플랫폼 및 예상 독자 접근 경로 | 권장 | 플랫폼 알고리즘·유료화 지점·화당 분량 관습이 다르다 |
| 톤앤매너 (밝음/어두움, 유머 비중, 잔혹성 수위, 성애 수위 등) | 필수 | 문장 교정·장면 연출 시 과하거나 부족한지 판단 기준 |
| 비교작(comp titles) 2~5개와 이 작품이 그것과 다른 지점 | 권장 | 시장성·차별화 판단, "이거 어디서 본 전개 같다" 감지에 사용 |
| 한 줄 차별화 포인트 ("이 작품만 할 수 있는 것") | 필수 | 전개가 평범해질 때 되돌아올 기준점 |
| 창작 계기/이 이야기를 왜 지금 쓰는가 | 선택 | 작가의 동기를 알아야 슬럼프 시 방향을 되짚어줄 수 있다 |

## 2. 작품 철학 & 핵심 주제

| 항목 | 필요도 | 왜 필요한가 |
|---|---|---|
| 이 작품으로 전하고 싶은 것 (주제/메시지) | 필수 | 결말·캐릭터 성장·상징을 주제에 수렴시키는 기준 |
| 작품이 실제로 "답을 내리는" 질문 vs "질문만 던지고 여운을 남기는" 질문 구분 | 권장 | 결말이 약하다고 느껴질 때, 미해결이 의도인지 실패인지 구분 |
| 절대 타협하지 않을 요소 (장르적 쾌감, 캐릭터 원칙 등) | 필수 | 상업성·독자 요구와 충돌할 때 무엇을 지킬지의 기준선 |
| 절대 쓰지 않을 것 (소재/전개/클리셰 금기) | 권장 | 초안 제안 시 사전에 걸러낼 수 있음 |
| 이 작품이 냉소적인가 낙관적인가, 인물을 심판하는가 이해하는가 | 선택 | 서술 시점의 태도, 대사 톤 조정에 영향 |

## 3. 세계관

| 항목 | 필요도 | 왜 필요한가 |
|---|---|---|
| 시공간적 배경 (시대, 지역, 현실기반/이세계/평행세계 등) | 필수 | 소품·어휘·묘사 고증 기준 |
| 세계 규칙 (마법 체계, 기술 수준, 초자연 규칙, 물리 법칙 예외) | 필수(장르가 요구 시) | 규칙 위반은 독자 이탈의 1순위 원인 — 룰 일관성 검증에 필요 |
| 규칙의 대가/제약 (능력에 반드시 따르는 비용) | 권장 | 사이다 전개가 개연성 없이 느껴지는 것을 방지 |
| 권력구조/사회체계/세력 관계 | 권장 | 정치극·세력 갈등 서사의 설득력 기준 |
| 세계관에서 "설명하지 않기로 한 것" (일부러 남겨둔 미스터리의 범위) | 선택 | 설정 구멍과 의도된 여백을 구분 |
| 세계관 용어집/지도/연표 (앱 내 문서·관계도와 연동 여부) | 선택 | 장기 연재 시 설정 충돌 방지용 마스터 자료 |

## 4. 플롯 & 서사 구조

| 항목 | 필요도 | 왜 필요한가 |
|---|---|---|
| 전체 줄거리 개요 (도입-중반-결말을 각각 몇 문단으로) | 필수 | 개별 화·장면이 전체 궤적에서 어디쯤인지 판단하는 지도 |
| 채택한 구조 모델 (3막 구조, 세이브 더 캣, 영웅의 여정, 기승전결, 회차형 클리프행어 구조 등) | 필수 | "구조가 무너졌는가" 진단은 기준 모델이 있어야 가능 |
| 메인 플롯 vs 서브플롯 목록과 각각의 역할 | 필수 | 서브플롯이 메인을 잠식하거나 방치되는 것을 감지 |
| 주요 전환점 (계기 사건, 1차 전환, 미드포인트, 2차 전환, 절정, 하강, 결말) | 필수 | 특정 화 집필 시 "지금 이 화가 구조상 어느 지점인가" 판단 |
| 결말의 형태와 도착 정서 (해피/새드/열린 결말, 독자가 마지막에 느낄 감정) | 필수 | "결말이 약한가" 진단은 목표 정서 대비로만 가능 |
| 예상 총 분량/화수와 대략적인 아크(arc) 구간 나누기 | 권장 | 장편 페이싱, 정체 구간 예측에 필요 |
| 각 아크별 목표 (이 구간이 끝나면 무엇이 바뀌어 있어야 하는가) | 권장 | 특정 구간이 늘어지는지 판단하는 기준 |
| 대안으로 검토했다가 버린 전개 (왜 버렸는지 포함) | 선택 | 같은 실수를 다시 제안하지 않기 위함 |

## 5. 캐릭터 성경 (Character Bible)

> 주요 인물마다 아래 항목을 채운다. 인물 수가 많으면 주인공/핵심 대립자부터 우선.

| 항목 | 필요도 | 왜 필요한가 |
|---|---|---|
| 표면적 목표(want)와 진짜 필요(need)의 차이 | 필수 | 캐릭터 행동이 "이상한지" 판단하는 핵심 축 — 원하는 것과 필요한 것의 괴리가 행동의 이유가 된다 |
| 결핍/상처(wound)와 그로 인한 거짓 믿음(lie) | 필수 | 성장 서사의 설득력은 이 거짓 믿음이 깨지는 과정에서 나온다 |
| 성장 곡선(arc): 시작 상태 → 끝 상태, 무엇이 계기로 변하는가 | 필수 | "성장이 설득력 있는가" 진단의 기준선 |
| 가치관과 행동 원칙 (무엇을 위해서라면 무엇까지 하는가) | 필수 | 캐릭터 붕괴(캐붕) 여부를 판단하는 가장 직접적 기준 |
| 넘지 않는 선 (이 인물이 절대 하지 않을 행동) | 필수 | "이 행동이 캐붕인지" 즉시 대조 가능 |
| 말투/어휘/화법 특징 (문장 길이, 존댓말 여부, 습관어) | 필수 | 대사 교정·문체 일관성 검증에 직접 사용 |
| 외형/신체 특징 | 권장 | 묘사 일관성 |
| 관계망 (다른 인물과의 역학, 힘의 우열, 감정) | 필수 | 관계 변화가 개연성 있는지 판단 |
| 대립자의 경우: 그 자신의 관점에서 정당한 이유 | 필수 | 평면적인 악역 방지, 갈등의 설득력 확보 |
| 조연의 서사적 기능 (플롯 촉매/대비/코믹 릴리프 등) | 권장 | 불필요하게 비대해지는 조연 감지 |
| 이 인물이 "무너지는" 신호 체크리스트 (이런 행동을 하면 캐붕이다) | 권장 | 장기 연재 중 캐릭터 일관성 자동 점검용 |
| 인물 간 말투 대비 샘플 대사 3~5줄 | 선택 | 다중 시점/대사 밀집 장면에서 목소리 구분 검증 |

## 6. 감정선 설계

| 항목 | 필요도 | 왜 필요한가 |
|---|---|---|
| 전체 감정 곡선 (긴장 상승/이완 지점을 대략적인 구간으로) | 권장 | 특정 구간이 늘어지거나 과부하되는지 진단 |
| 독자에게 유도하려는 감정의 순서 (예: 불안→기대→카타르시스) | 권장 | 장면 연출 시 톤 선택의 기준 |
| 주요 카타르시스 지점과 그 전에 쌓아야 할 긴장 | 필수 | "이 장면이 어색하다"는 피드백을 감정 축적 부족 여부로 진단 가능 |
| 이완 구간(코믹 릴리프, 일상 파트) 배치 계획 | 선택 | 긴장 과다로 인한 피로도(독자 이탈 원인) 방지 |
| 로맨스/관계 서사가 있다면 감정 곡선의 밀당 지점 | 선택(장르 요구 시 필수) | 로맨스 장르 문법상 페이싱 오류 방지 |

## 7. 복선 & 떡밥 관리

| 항목 | 필요도 | 왜 필요한가 |
|---|---|---|
| 이미 심어둔 복선 목록 + 심은 화/장면 + 회수 예정 시점 | 필수 | "복선이 충분한가", "회수를 놓쳤는가" 진단에 직접 사용되는 트래킹 표 |
| 작가만 아는 진짜 답 (미스터리/반전의 실제 정답) | 필수 | 오해를 유도하는 서술과 페어플레이(단서 제공) 여부를 구분하는 기준 |
| 단서 배치 강도 (독자가 눈치채도 되는 정도인지, 완전히 숨겨야 하는지) | 권장 | 반전이 뜬금없는지 vs 너무 뻔한지 판단 |
| 떡밥 회수 누락 방지 트래킹 방식 (본 문서 갱신 주기 등) | 권장 | 장기 연재 최대 리스크인 "떡밥 방치"를 구조적으로 방지 |

## 8. 장르 문법 & 독자 기대

| 항목 | 필요도 | 왜 필요한가 |
|---|---|---|
| 이 장르 독자가 당연히 기대하는 요소(트로프) 목록 | 필수 | 장르 문법을 따를지 비틀지 판단하는 근거. 없으면 "이건 이 장르에서 꼭 필요한가?" 질문에 답 불가 |
| 각 트로프를 정석대로 쓸지/비틀지/생략할지 | 권장 | 클리셰 사용이 의도적 선택인지 안일함인지 구분 |
| 이 작품이 의도적으로 장르 관습을 깨는 지점과 그 이유 | 권장 | 독자 반발 예상 지점을 사전에 식별 |
| 화당 필수 요소 (연재물의 경우: 클리프행어, 사이다 지점 등 관습) | 선택(연재물은 권장) | 화별 원고 작성 시 리듬 점검 기준 |

## 9. 독자층 & 시장성

| 항목 | 필요도 | 왜 필요한가 |
|---|---|---|
| 핵심 타겟 독자 프로필 (연령대, 성향, 평소 소비 작품) | 필수 | "이 장면/전개가 타겟 독자에게 통하는가" 판단 기준 |
| 이 작품의 상업적 강점 (한 줄로 팔 수 있는 지점) | 권장 | 출판성/상업성 질문에 답하는 근거 |
| 상업적 약점/리스크 요소 | 권장 | 미리 알고 있어야 보완 전략을 짤 수 있음 |
| 예상 이탈 지점 (도입부 속도, 초반 정보량, 특정 전개 등) | 권장 | "독자가 이탈할까" 질문에 구체적으로 답하기 위한 근거 |
| 플랫폼별 관습과의 정합성 (연재 주기, 화당 분량, 무료/유료 분기점) | 선택 | 연재형인 경우 구조 설계에 직결 |

## 10. 장기 연재 리스크 관리 (장편 특화)

| 항목 | 필요도 | 왜 필요한가 |
|---|---|---|
| 설정 충돌 방지용 마스터 자료 (연표, 지도, 세력도, 용어집) 존재 및 위치 | 권장 | 화수가 쌓일수록 설정 모순이 누적되는 것을 구조적으로 방지 |
| 등장인물 증가 관리 원칙 (언제 새 인물을 추가/퇴장시킬지) | 선택 | 인물 과다로 인한 서사 분산 방지 |
| 페이스 조절 계획 (전개가 늘어질 때의 대응 원칙) | 권장 | 정체기 진입 조기 감지 |
| 작가의 여유 플롯/예비 전개 (슬럼프·소재 고갈 대비) | 선택 | 장기 연재 중단 리스크 대비 |
| 최근 갱신일 기준 이 브리프의 최신 버전 관리 방식 | 선택 | 초기 설정과 실제 집필본이 벌어지는 것을 방지 |

## 11. 문체 & 문장 스타일

| 항목 | 필요도 | 왜 필요한가 |
|---|---|---|
| 시점 (1인칭/3인칭 제한/전지적, 다중 시점 여부) | 필수 | 문장 교정 시 시점 이탈(head-hopping 등) 검증 기준 |
| 시제 | 필수 | 문장 일관성 검증 |
| 문장 리듬 선호 (단문 위주/만연체, 대사·지문 비율) | 필수 | "문장이 안 써진다"는 상황에서 톤에 맞는 대안 제시 근거 |
| 지양하는 문장 습관/클리셰 표현 | 권장 | 교정 시 자동 필터링 기준 |
| 참고하고 싶은 문체의 실제 작가/작품 (모방이 아닌 참고) | 선택 | 톤 캘리브레이션 |

## 부록 A. Claude가 이후 상시 사용할 진단 체크리스트

아래는 브리프가 채워진 뒤, 다음과 같은 질문에 답할 때 Claude가 대조할 기준이다. 참고용이며 직접 채우는 항목은 아니다.

- **문장이 안 써진다** → 11장(문체), 6장(감정선 해당 구간의 목표 정서) 대조
- **특정 장면이 어색하다** → 5장(관계망·가치관), 6장(감정 축적 여부), 8장(장르 기대) 대조
- **캐릭터 행동이 이상한지 모르겠다** → 5장(want/need, 넘지 않는 선, 가치관) 대조
- **복선이 충분한가** → 7장(회수 트래킹 표)
- **결말이 약한가** → 4장(도착 정서), 2장(답을 내릴 질문 vs 여운 남길 질문)
- **독자가 이탈할까** → 9장(예상 이탈 지점), 6장(긴장-이완 배치)
- **출판성/상업성이 있는가** → 9장, 1장(차별화 포인트)
- **설정 충돌이 있는가** → 3장(세계 규칙), 10장(마스터 자료)
- **특정 화를 어떻게 써야 할까** → 4장(구조상 위치), 8장(화당 필수 요소)
- **특정 대사를 어떻게 바꿔야 할까** → 5장(말투/화법)
- **주인공 성장이 설득력 있는가** → 5장(성장 곡선, 거짓 믿음이 깨지는 계기)
- **플롯 구조가 무너졌는가** → 4장(구조 모델, 전환점)

## 부록 B. 작성 순서 가이드

한 번에 다 채우지 말고 아래 순서로 진행하는 것을 권장한다. 뒤 단계는 앞 단계 없이는 구체화하기 어렵고, 앞 단계가 흔들리면 뒤 단계 전체가 흔들리기 때문이다.

1. **1장 로그라인 & 정체성 + 2장 작품 철학** — 이 작품의 존재 이유를 먼저 고정한다.
2. **3장 세계관 (규칙 중심으로만 우선)** — 이야기가 일어날 무대의 물리 법칙만 먼저.
3. **5장 캐릭터 성경 (주인공, 핵심 대립자만 우선)** — 이야기를 움직이는 엔진.
4. **4장 플롯 & 서사 구조 (전체 개요 + 전환점)** — 인물이 정해져야 플롯이 그 인물에 맞게 나온다.
5. **7장 복선 트래킹 표 초안** — 플롯의 전환점이 정해져야 어디에 복선을 심을지 나온다.
6. **6장 감정선 + 8장 장르 문법** — 장면 단위 연출 전, 리듬과 장르 기대치 정렬.
7. **9장 독자층 & 시장성 + 10장 장기 연재 리스크** — 연재 실무 관점 점검.
8. **11장 문체 + 12장 상징 + 13장 레퍼런스** — 실제로 몇 화 써본 뒤 역으로 정리하는 편이 더 정확하다. 초고 집필 시작 후에 채워도 무방.

이후 단계: 1~5번 항목만 채운 상태로도 집필 시작이 가능하다. 채운 내용을 공유하면 그 시점부터 장면·대사·전개에 대한 구체적 피드백을 시작할 수 있다. 이 문서는 고정 문서가 아니라 집필하면서 계속 갱신하는 살아있는 자료이며, 특히 5장(캐릭터)과 7장(복선 트래킹)은 매 화 갱신을 권장한다.
